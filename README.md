# 📊 Tableau Intern Dashboard Deployment

## 🚀 1. Project Approach & Overview
* **Objective:** Deployed an optimized analytics dashboard for Veda Tech to visualize key business metrics.
* **Layout Optimization:** Configured dashboard containers to use the **Entire View** dynamic sizing layout. This fixed the display issues, maximizing visual screen coverage without requiring vertical or horizontal scrolling.

## 🔄 2. Deployment Configuration & Rollback Evidence
* **Deployment Method:** Managed and version-controlled via GitHub repository files.
* **Rollback Strategy:** Version history logs are maintained in this repository. In the event of layout breaks or data source corruption, the deployment configuration can instantly be reverted to a prior stable commit state.

## 🎯 3. Project Outcome
* Fully scalable reporting view ready for stakeholder presentation.
* Deployment configuration code and documentation stored centrally.
